## 协议



### 出厂配置

| 帧头1 | 0xBB | 1字节 | 固定 |
| :---: | :---: | :---: | :-- |
| 帧头2 | 0x55 | 1字节 | 固定 |
| 模式 | 0x01、0x02、0x03 | 1字节 | 三个档位选其一 |
| freq / 输出频率（KHZ） |  | 2字节 | 范围：500-1000 |
| 程序内部计算成pwm占空比 / VPP（v） | | 1字节 | 范围：40-120v |
| 刺激时长（毫秒） | | 2字节 | 范围：1-1000ms |
| 刺激间隔（毫秒） | | 2字节 | 范围：0-1000ms |
| 间隔（秒） | | 2字节 | 范围：0-600s |
| 脉冲时长（秒） | | 2字节 | 范围：1-600s |
| 总时长（分钟） | | 1字节 | 范围：1-60min |



### 启动

|     帧头1      |          0xBB          | 1字节 | 固定                          |
| :------------: | :--------------------: | :---: | :---------------------------- |
|     帧头2      |          0x66          | 1字节 | 固定                          |
|      模式      |    0x01、0x02、0x03    | 1字节 | 三个档位选其一                |
| 总时长（分钟） |                        | 1字节 | 启动范围：1-60min，关闭写0x00 |
|      状态      | 0x00（关）、0x01（开） | 1字节 | 开关                          |

启动模式1五分钟，`BB 66 01 05 01`

关闭模式1，`BB 66 01 00 00`
