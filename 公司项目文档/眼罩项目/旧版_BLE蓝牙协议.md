
## 帧格式

- 协议中的多字节整数均采用小端序。CMD、状态码及普通字节数组不涉及大小端。

```txt
BB 55 | LEN_L LEN_H | CMD | DATA(N)  // 帧格式
```

|  说明  | 字节位  |      协议       |                  备注                   |
| :--: | :--: | :-----------: | :-----------------------------------: |
| 帧头1  |  0   |      BB       |                  固定值                  |
| 帧头2  |  1   |      55       |                  固定值                  |
| 数据长度 | 2-3  | `LEN_L LEN_H` |      小端序（表示 **1字节CMD + n字节数据位**）      |
| CMD  |  4   |     具体命令码     |              1字节，不涉及大小端               |
| 数据位  | 5-64 |      可变       | 小端序  长度为0-60可变长度，由 **数据长度 -1（CMD）**决定 |


```txt
// 示例

BB 55 01 00 01       // 上位机发送
BB 55 02 00 01 00    // 下位机回复

帧头     BB 55
数据长度  02 00  --小端序-->  0002 ->  表示cmd+数据位长度为 2
CMD      01     -->  对应通信测试指令
数据位    00     -->  表示指令执行成功
```

## CMD指令

```c
typedef enum {
    HOST_CMD_TEST             = 0x01, /* 通信测试 */
    HOST_CMD_HW_LINK_TEST     = 0x03, /* SPI链路测试 （仅测试使用，正式版不上线） */
    HOST_CMD_BATTERY_GET      = 0x05, /* 查询电池剩余电量百分比 */
    HOST_CMD_EEG_SET_DURATION = 0x0C, /* 设置采集时长：2字节小端秒数，0表示不限时 */
    HOST_CMD_EEG_SEND         = 0x0D, /* 设备主动上报脑电原始数据 */
    HOST_CMD_EEG_START        = 0x0E, /* 开始脑电采集 */
    HOST_CMD_EEG_STOP         = 0x0F, /* 停止脑电采集 */
    HOST_CMD_SENSOR_SEND      = 0x1F, /* 设备主动上报BMI270六轴原始数据 */
} m_ble_cmd_t;
```

## 错误码

```c
typedef enum {
    HOST_ERR_NONE    = 0x00,           /* 命令执行成功 */
    HOST_ERR_EXECUTE = 0x01,           /* 命令执行失败 */
} m_ble_error_t;
```


## 示例

### 通信测试

```txt
// 上位机发送
BB 55 01 00 01

// 下位机回复
BB 55 02 00 01 00    // 成功

BB 55 02 00 01 01    // 失败
```

测试当前通信 末尾00表示成功，01表示失败


### 电量查询

电量查询回复的DATA只有一个字节，该字节直接表示电量百分比，不包含通用错误码
```txt
// 上位机发送
BB 55 01 00 05


// 下位机回复
BB 55 02 00 05 36
// 假设当前电量为54%，十六进制为 0x36
```

### 设置采集时长

```txt
// 上位机发送
BB 55 03 00 0C 00 00    // 设置0s，默认0s，表示不限时

BB 55 03 00 0C 2C 01    // 0x012c = 300 设置采集300s

BB 55 03 00 0C 96 00    // 150s

BB 55 03 00 0C 78 00    // 120s

BB 55 03 00 0C 0A 00    // 0x000a = 10  设置采集10s


// 下位机回复
BB 55 02 00 0C 00    // 成功

BB 55 02 00 0C 01    // 失败
```


### 开始采集

如果设置了采集时间，则采集时间结束会向上位机发送  `BB 55 02 00 0F 00` 表示采集结束成功

```txt
// 上位机发送
BB 55 01 00 0E


// 下位机回复
BB 55 02 00 0E 00    // 成功   外设检查和启动成功时回复

BB 55 02 00 0E 01    // 失败   外设检查和启动失败时回复
```

### 停止采集

如果通过`0x0C`设置了固定采集时长，到期后不需要上位机发送停止命令。采集结束会向上位机发送  `BB 55 02 00 0F 00` 表示采集结束成功

设备已经处于停止状态时再次发送停止命令，仍回复成功。

```txt
// 上位机发送
BB 55 01 00 0F     // 上位机主动停止采集，可以打断设置的采集时间


// 下位机回复
BB 55 02 00 0F 00    // 成功   外设检查和启动成功时回复
```


### 脑电数据

一个完整逻辑协议帧为65字节。

| 帧头   | 2字节       |
| ---- | --------- |
| 数据长度 | 2字节（小端序）  |
| 命令   | 1字节       |
| 数据位  | 60字节（小端序） |

DATA包含30个ADS1118原始采样值，每个采样值为16位有符号整数，采用小端序排列。

```sh
// 一帧EEG数据
BB 55 
3D 00 
0D // 0D表示 EEG 数据  EEG一组为2字节，60字节分30组 小端序
E4 10 → 0x10E4 → 4324
7F F4 → 0xF47F → -2945
92 FD 
25 AA 
C1 D7 01 02 B9 DC 2A A5 2F A2 50 E2 C5 07 E6 DF 4C 81 CE D5 57 F7 BB 0F 0E DC D2 A3 F8 A5 8E F1 2F F3 E0 E3 D7 BC A5 F5 FD 09 88 D1 CD 82 4E DF 92 0E D6 0C
```

### 六轴数据

一个完整逻辑协议帧为65字节。

DATA包含5组BMI270六轴原始数据。每组12字节，依次为GX、GY、GZ、AX、AY、AZ；每个轴为16位有符号整数，采用小端序。

| 帧头   | 2字节 BB 55       |
| ---- | --------------- |
| 数据长度 | 2字节（小端序）        |
| 命令   | 1字节             |
| 包序号  | 2字节（小端序）0-65535 |
| 数据位  | 60字节（小端序）       |
| 帧尾   | 3字节 AA BB CC    |

```c
// 一帧BMI270数据  
BB 55 3D 00 1F 00 00 92 00 ED FF 34 BF 42 01 F9 FC 38 00 05 00 EB FF 41 BF 48 01 CE FC E4 FF 4E FF E7 FF 4B BF 51 01 0A FD 8D FF D1 FF E6 FF 4E BF 44 01 27 FD 72 FF 87 00 EC FF 40 BF 46 01 04 FD
    
BB 55 // 帧头
3D 00 // 命令 + 数据长度 --> 0x003d --> 61
1F 	  // 命令 1F 表示位BMI270数据  0D 表示EEG数据

// 数据位 60字节 BMI一组为12字节 数据位60字节分5组 小端序
// GX GY GZ AX AY AZ
00 00 92 00 ED FF 34 BF 42 01 F9 FC --> 0000 0092 ffed bf34 0142 fcf9
```

```txt
// 上位机发送
BB 55 01 00 F1


// 下位机回复
BB 55 13 00 F1       
01 03 01 00 02   // 01表示软件版本  03表示后边三字节  01 00 02 表示版本1.0.2
02 03 00 00 01   // 02表示硬件版本  03表示后边三字节  00 00 01 表示版本0.0.1
03 06 41 42 01 02 03 04  // 03表示蓝牙mac  06表示后边6个字节  经典蓝牙地址 41:42:01:02:03:04
```
