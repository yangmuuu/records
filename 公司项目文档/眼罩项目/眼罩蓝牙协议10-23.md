## 工作流程

设备上电，连接BLE且检测用户佩戴正常，BLE持续输出采集数据

BLE断开且用户正常佩戴的情况下，设备端不会停止采集，buff会缓存一部分（64帧）最新数据，等待BLE再次连接，

BLE正常，但是检测到用户非正常佩戴，设备端会停止采集，并给APP一个信号帧，表明用户非正常佩戴，直到用户正常佩戴后继续工作。若长时间非正常佩戴，会进入休眠或者关机，在休眠或者关机前会给APP一个信号帧

## 蓝牙双连

BLE连接成功后，向FF20通道写入 0x01，发送方式为有返回写入，则可蓝牙双连

## 数据帧格式

| 帧头   | 2字节  0xBB 0x55                                           |
| ---- | -------------------------------------------------------- |
| 数据长度 | 2字节（小端序）  命令1字节 + 帧序号2字节 + 数据位60字节                       |
| 命令   | 1字节                                                      |
| 帧序号  | 2字节（小端序）0-65535循环     BMI一帧数据是5组，一组12字节；脑电一帧数据是30组，一组2字节 |
| 数据位  | 60字节（小端序）                                                |


BMI的帧序号 和 脑电的帧序号分开统计，两个计数器

### 电量_版本号等参数信息

BLE连接成功后，打开通知，第一帧为此帧
固定帧长26字节，直接读取第25字节表示剩余电量，
电量由SDK内部计算，电压每变化30mv，且百分比发生变化，会再次发送当前帧

```c
BB 55 // 帧头
16 00 // 0x0016 表示后边一共22字节
F2 // CMD
01 03 01 00 02 // 01表示软件版本 03表示后边3字节，01 00 02 表示1.0.2版本
02 03 00 00 01 // 02表示硬件版本 03表示后边3字节，00 00 01 表示0.0.1版本
03 06 41 42 01 02 03 04  // 03表示MAC地址。06表示后边6字节，地址41:42:01:02:03:04
04 01 17 // 04表示电量，01表示后边1个字节，0x17 -> 23 表示电量剩余23%
```

### 佩戴检测

```c
BB 55 02 00 F1 01 // 非正常佩戴，停止采集，每隔 5 秒重复上报

BB 55 02 00 F1 00 // 正常佩戴，立刻上报一次，恢复采集，
```
